# AI Tools Hub 🚀
A Hugo-based blog for reviewing and promoting AI tools and SaaS products through affiliate marketing.
## Quick Start
### Local Development
1. Download Hugo: https://gohugo.io/installation/
2. Run: `hugo server -D`
3. Open: http://localhost:1313
### Deploy to Netlify
1. Push this repo to GitHub
2. Connect to Netlify
3. Done! Your site will be live in minutes
## Adding Affiliate Links
1. Edit `netlify/functions/redirect.js`
2. Add your affiliate links to the redirects object
3. Use `/go/tool-name` in your blog posts
