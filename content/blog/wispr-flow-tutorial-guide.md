## Introduction
Wispr Flow is an AI voice dictation tool that lets you type by speaking — and it's significantly faster than typing. This guide will walk you through everything from installation to advanced techniques. If you're curious about real-world results, check out my [Wispr Flow Review: One Month of Voice Dictation](/blog/wispr-flow-review-real-experience/).
## Step 1: Download and Install
### System Requirements
- macOS 12+ or Windows 10+
- Stable internet connection
- A microphone (built-in works, external is better)
### Installation Steps
1. Visit the Wispr Flow website
2. Click download and select your OS
3. Run the installer and follow the prompts
4. Launch Flow — you'll see a clean menu bar icon
**Pro tip**: Restart your computer after installation to ensure everything works properly.
## Step 2: Basic Setup
### Choose Your Microphone
Open Flow settings, go to Audio, and select your mic. Built-in laptop mics work fine in quiet environments. For best results, use an external USB or headset mic.
### Configure Shortcuts
The default activation shortcut is double-tap Ctrl (Windows) or double-tap Command (Mac). You can change it to anything you like — I use Alt+Space.
### Language Settings
Flow supports mixed-language input automatically. Speak Chinese, get Chinese. Speak English, get English. No manual switching required.
## Step 3: Start Using Flow
### Basic Operation
1. Place your cursor where you want to type
2. Double-tap Ctrl (or your shortcut)
3. Start speaking
4. Double-tap again to stop
That's it. No need to open a specific app. Flow works in any text field.
### Voice Commands
Flow supports voice commands to boost your efficiency:
- **"New paragraph"**: Start a new paragraph
- **"New line"**: Line break
- **"Period"**, **"Comma"**, **"Question mark"**: Manual punctuation control
- **"Delete"**: Remove the last thing you said
- **"Undo"**: Undo last action
**Note**: You usually don't need manual punctuation — Flow handles it automatically. Use these commands only when you need specific control.
## Step 4: Advanced Tips
### Tip 1: Writing Long-Form Content
Don't try to dictate an entire article in one go. Speak 2-3 sentences, pause for Flow to process, then continue. This gives you better accuracy and lets you organize your thoughts.
### Tip 2: Mixed-Language Dictation
Flow handles mixed Chinese and English remarkably well. Say "build an API endpoint using Python" and it outputs exactly that. No language switching needed.
### Tip 3: Custom Vocabulary
If you use industry-specific terms frequently, add them to Flow's custom vocabulary in settings. This significantly improves recognition accuracy for your niche.
### Tip 4: The Polishing Feature
Flow doesn't just transcribe — it polishes. It removes filler words, adjusts sentence flow, and optimizes phrasing. If you find it too aggressive, you can adjust the intensity in settings.
### Tip 5: Integrate With Your Tools
Combine Flow with your daily tools for maximum productivity:
- **VS Code**: Dictate code comments and documentation
- **Notion**: Take notes and write articles by voice
- **Slack**: Reply to messages hands-free
- **Gmail**: Compose emails while doing other things
- **Obsidian**: Keep a voice journal
## Step 5: Frequently Asked Questions
### Q: How accurate is Flow?
A: In a quiet environment, expect 95%+ accuracy. Background noise will reduce this — use a noise-canceling mic for best results. For a detailed accuracy comparison with other tools, see [Wispr Flow vs Traditional Voice Dictation](/blog/wispr-flow-vs-traditional-voice-input/).
### Q: Can I write code with Flow?
A: Comments and documentation, yes. Actual code, not recommended. Syntax is too complex for voice input.
### Q: Does Flow work offline?
A: No, it requires an internet connection since AI processing happens in the cloud.
### Q: Is my data private?
